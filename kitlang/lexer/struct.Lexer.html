fn documentation(&mut self) -> Option<Token>

Parses a documentation block from the cursor position.

§Details

Parses every line that starts with ‘///’ until the next line with a non-documentation or comment token is found, as a documentation token.

fn numeric_literal(&mut self) -> Option<Token>

Parses a numeric literal from the cursor.

§Details

All support underscores (‘_’) for delimiting, underscores are to be read as non-influential characters. Can be of the form:

  • Binary (‘0b01010101’)
  • Hexadecimal (‘0xFA’)
  • Octal (‘0o80’)
  • Decimal (‘820’) and (2.1023)
  • E-notation (‘2.1e6’)
