Module verifier 

Source
Expand description

The purpose of this module is to verify that all reference paths have been resolved after the resolution phase of the compiler.

Traverses the HLIR and records any RefPath::Unresolved, and aggregating all such instances into one ResolverError containing all unresolved references.

This file does not perform resolution or mutate the HLIR. It only detects unresolved references and surfaces them as diagnostics for the resolution pipeline.

This module is exclusively focused on verification of unresolved references.
