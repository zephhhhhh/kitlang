Struct AssociatedReferenceMapper 

Source 
struct AssociatedReferenceMapper<'a> {
    pub meta: &'a mut ProgramMetaData,
    pub global_functions: HashMap<String, OwnerDefId>,
    pub path_stack: Vec<IdentPath>,
    pub impl_path_lut: Vec<(OwnerDefId, IdentPath)>,
    pub stage1_complete: bool,
    pub errors: Vec<ResolverError>,
    pub resolution_failures: Vec<(HirId, SpannedIdentPath, ResolutionFailure)>,
}

Fields§

§meta: &'a mut ProgramMetaData§global_functions: HashMap<String, OwnerDefId>

Tracks all defined global functions, for quick lookup during resolution. We check this map first when resolving single-segment paths.

§path_stack: Vec<IdentPath>

Stack of identifier paths representing the current scope during traversal. This is used if we need to temporarily change scope while visiting nested items, before reverting back to the previous scope.

§impl_path_lut: Vec<(OwnerDefId, IdentPath)>

Lookup table of all impl items encountered during the first pass, so we can defer visiting them until later.

§stage1_complete: bool

Indicates whether the first stage of mapping (building namespaces) is complete.

§errors: Vec<ResolverError>

Collected resolver errors encountered during mapping.

§resolution_failures: Vec<(HirId, SpannedIdentPath, ResolutionFailure)>

Collected resolution failures for unresolved references, to be reported after resolution. Each entry contains the HirId of the item that failed, the SpannedIdentPath it is trying to access, and the ResolutionFailure reason.
