Struct HLIRLowerer

struct HLIRLowerer<'a> {
    hlir: &'a mut HLIR,
}
Expand description

This struct is how we store and maintain the HLIR while we lower from AST to HIR. Contains all the logic for doing the lowering.

pub fn build_hir_representation(&mut self, ast: &ASTRoot) -> LowerResult<()>

Builds the complete HIR representation from an AST root.

This is the main entry point for the HIR lowering process. It creates a root module to contain all top-level items and then walks the AST to populate the HIR.

§Returns

Ok(()) on success, or a LoweringError if any part of the lowering fails.
