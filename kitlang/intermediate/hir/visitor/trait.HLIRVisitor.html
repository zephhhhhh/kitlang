Expand description

Provides an interface from traversing the HLIR tree.

Functions named super_ are default implementations that traverse the tree further, and are not meant to be overriden. They should be called during the corresponding visit_ function implementations to keep traversing the tree further, you can also omit this under conditions if you do not want traversal to continue.

The super_ functions will call the appropriate visit_ functions for child nodes, which should then call the super_ functions to continue traversal, if desired.

By default all visit_ functions call their corresponding super_ functions, so only the kinds of nodes you want to handle need to be overridden/implemented.

Implementations should be provided by overriding the visit_ functions for the specified types you want.

To start traversal, the function visit_root should be called on this trait with a reference to the HLIR.
