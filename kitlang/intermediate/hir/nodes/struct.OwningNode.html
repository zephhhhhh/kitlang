Struct OwningNode 

Source 
pub struct OwningNode {
    pub kind: OwningNodeKind,
    pub nodes: Vec<HirNode>,
}
Expand description

Owning HIR node, which contains other HIR nodes and manages their scope. Has a kind, which describes what type of owning node it is (e.g. an Item or an Item within an impl block).

Fields§

§kind: OwningNodeKind§nodes: Vec<HirNode>

The HIR nodes owned by this owning node.
