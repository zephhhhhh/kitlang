Module intermediate

Expand description

Houses the different levels of IR used in the compiler’s architecture, as well as resolution and type checking.

The different levels are:

  • High level IR (HIR): A more abstract representation that closely resembles the source code AST representation, but in a more ‘flattened’ and analyzable form, where each expression, function, statement etc, is easily indexable with a unique ID.
  • Middle level IR (MIR): A lower-level representation that is closer to machine code, focusing on control flow and data flow. This form is essentially comprised of just data operations, jumps, function calls and assignments.

Modules§

hir
The HIR module provides the primary IR structure for the compiler. It transforms the AST into a flatter representation optimized for analysis passes like resolution and type checking.
mir
The MIR module provides a control flow based IR suitable for interpretation, further optimization, and eventually lowering further into machine code or bytecode.
resolver
The resolver module contains multiple resolvers that are each responsible for resolving different kinds of references within a Kitlang program.
type_check
The purpose of this module is to perform type checking on the resolved HLIR after reference resolution. It validates that all type rules are followed, ensures type compatibility across operations, and infers types where explicit annotations are absent.
